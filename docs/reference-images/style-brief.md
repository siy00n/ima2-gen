# Mobile Node Workspace Style Brief

Generated reference text is for layout and tone only. Do not copy it literally into implementation.

## Visual Thesis

A restrained mobile product workspace for image workflow editing: dark, dense, touch-first, and focused on one selected node at a time.

## Reference Profile

- Project type: product app / creative workflow tool
- Target surface: mobile web, iPhone Safari and Android Chrome
- Canvas / viewport: mobile portrait, 390x844
- Fidelity: high-fi implementation reference
- Primary workflow: select a node, edit prompt, adjust generation settings, generate, branch, inspect lineage, and configure parent connection transfer

## Visual System

- Background: near-black app shell with subtle panel separation.
- Surfaces: deep charcoal panels, 12-16px radius, thin low-contrast borders.
- Accent: purple for primary actions and selected state.
- Semantic chips: green for ready, amber for settings/attention, cyan for image transfer, pink for context transfer.
- Typography: compact sans for product labels, mono for metadata and short control labels.
- Density: compact but touchable. Primary buttons around 48-54px high, chips around 28px high.
- Motion tone: bottom sheets and tab transitions should be quick and calm. Avoid decorative motion.

## Interaction Direction

- Mobile Node mode should not be a tiny desktop graph editor.
- The default surface is a focused node editor.
- Graph structure appears as branch lists and a map overview, not as the main editing canvas.
- Edge transfer settings live in an explicit connection settings screen/sheet.

## Common Negative Prompt

Avoid marketing hero layouts, colorful dashboards, freeform desktop graph manipulation, hover-only controls, decorative gradients, fake API keys, private URLs, emails, credentials, and dense desktop tables.
